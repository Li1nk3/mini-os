# 操作系统课程设计 — 综合演示系统

> 班级:2026 计算机科学与技术 1 班
> 课程:《操作系统》课程设计
> 平台:Linux (Ubuntu 22.04, GCC 11+)
> 语言:C11 + POSIX Threads

本项目实现了操作系统课程设计**基础必做部分**(占比 70%)的全部 4 个模块,提供统一的命令行交互菜单。

## 一、目录结构

```
.
├── Makefile               # 构建脚本
├── src/
│   ├── main.c             # 主菜单入口
│   ├── common/util.{c,h}  # 通用输入/输出工具
│   ├── scheduling/        # 处理机调度: FCFS / SJF / RR / Priority
│   ├── memory/            # 内存管理: 分区(FF/BF/WF) + 页面置换(FIFO/LRU/OPT)
│   ├── sync/              # 进程同步: 生产者-消费者 / 读者-写者 / 哲学家
│   └── filesystem/        # 简易文件系统: 超级块 + 位图 + inode + 目录树
├── tests/                 # 自动化测试
└── docs/                  # 报告与说明
```

## 二、构建与运行

```bash
make            # 构建主程序 build/os_demo
make tests      # 构建测试程序 build/test_*
make run        # 直接运行
make clean      # 清理构建产物
```

直接运行:
```bash
./build/os_demo
```

运行测试:
```bash
./build/test_scheduling     # 调度算法正确性测试(断言)
./build/test_memory         # 内存管理测试(断言,含经典 Belady 序列)
./build/test_sync           # 同步并发测试(目视)
./tests/run_fs_demo.sh      # 文件系统端到端脚本测试
```

## 三、模块说明

### 1. 处理机调度 (`src/scheduling/`)

| 算法 | 说明 |
| --- | --- |
| FCFS | 按到达时间排队,非抢占 |
| SJF  | 短作业优先,非抢占,在已到达的就绪进程中选服务时间最短 |
| RR   | 时间片轮转,可配置 quantum |
| Priority | 优先级调度,数值小者优先,非抢占 |

输出包括:
- ASCII 甘特图(自适应宽度,合并相邻同进程段)
- 完成时间、周转时间、等待时间、响应时间、带权周转时间
- 平均统计指标

提供 "全部算法对比" 模式,使用同一组进程数据连续运行 4 种算法,便于性能对比。

### 2. 内存管理 (`src/memory/`)

**动态分区**:
- First-Fit:扫描分区表,选第一个能放下的空闲分区
- Best-Fit :选最小的能放下的分区,减少外部碎片但易产生小碎片
- Worst-Fit:选最大的能放下的分区,产生较大剩余便于后续使用

每次申请/释放后输出分区表(ID、起址、大小、状态、PID),释放时自动合并相邻空闲分区。

**页面置换**:
- FIFO:先进先出,以装入顺序为依据
- LRU :最近最久未使用,基于上次访问时间
- OPT :最佳置换,预测未来最久不用的页面(用于对比下限)

输出包括逐步访问轨迹、每步帧状态、缺页/命中标记、最终缺页率统计。

`tests/test_memory.c` 使用 Belady 经典访问串 `7,0,1,2,0,3,0,4,2,3,0,3,2,1,2,0,1,7,0,1` 在 3 帧条件下断言 FIFO=15 次、LRU=12 次、OPT=9 次缺页。

### 3. 进程同步 (`src/sync/`)

基于 `pthread` 与 `<semaphore.h>`:

| 问题 | 同步机制 |
| --- | --- |
| 生产者-消费者 | empty / full 信号量 + 互斥锁保护缓冲区,环形数组 |
| 读者-写者 | 互斥锁 + 计数,提供读者优先与写者优先两种实现 |
| 哲学家就餐 | 两种避免死锁策略:① 资源分级(总是先拿编号小的筷子) ② 限制最多 n-1 人同时尝试取叉 |

输出每个步骤的执行轨迹,便于观察并发交错。

### 4. 文件系统 (`src/filesystem/`)

基于单一文件 `fs.img` 模拟磁盘:

```
| 超级块 | 块位图 | inode表 | 数据区 |
   1块     1块      ?块       剩余
```

参数:
- 总块数 1024,块大小 512B,总容量 512KB
- inode 数 128,每个 inode 直接指向最多 8 个数据块
- 支持单级目录、cd / mkdir / create / write / cat / rm / ls / stat / bitmap

空闲空间管理使用**位图(bitmap)**;目录数据块中存放定长 `DirEntry` 数组。所有元数据更新后立刻落盘 (`persist_meta` + `fflush`),掉电后再次 `mount` 可恢复。

## 五、设计要点

1. **甘特图实现**:用结构体数组记录 `(pid, begin, end)` 段,相邻同 pid 段合并,绘制时按持续时间比例分配宽度,便于直观看出调度行为差异。
2. **RR 队列正确性**:每次推进时钟后立即把刚到达的进程入队,确保新到进程不会"漏掉"。
3. **分区合并**:`free` 后扫描整个分区表,与左右空闲分区合并(线性时间),避免外部碎片累积。
4. **写者优先**:用额外的 `r_try` 锁,在有写者等待时阻塞新读者进入临界区,避免写者饥饿。
5. **资源分级**:哲学家问题的资源分级策略,通过保证所有线程按全局相同顺序获取资源,破坏循环等待条件,数学上保证无死锁。
6. **位图分配**:`alloc_block` O(n) 扫描,数据块数较少时简单可靠;持久化时整块写回。
